# Proposal

## Description

I'm going to make Dungeon Escape. It is 2D top-down advemture game where the player explores a mysterious dungeon and try to find the way out. The player must navigate through walls, collect keys, avoid enemies, and unlock the exit door to complete the level.


## Needs to Have List

- Player movement using keyboard controls.
- A dungeon map with walls and walkable paths.
- Collision detection between the player and walls.
- A key collection system.
- A locked exit door.
- Enemies that move around the dungeon.
- Collision detection between the player and enemies.
- Start, Playing, Game Over, and Victory states.
